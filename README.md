# This repository is a structured learning and practice collection for Python programming, data analysis, machine learning algorithms, and applied projects.

## Python
Contains core Python fundamentals required for data science and machine learning.
Topics include data types, control flow, functions, object-oriented programming, file handling, and exception handling.
Purpose is to build a strong programming foundation before applying machine learning concepts.

## Pandas
Focuses on data manipulation and preprocessing using the Pandas library.
Includes data loading, cleaning, handling missing values, filtering, grouping, aggregation, and exploratory data analysis.
Used to prepare raw datasets before model training.

## Regression Models
Covers supervised learning algorithms for predicting continuous values.
Includes simple linear regression, multiple linear regression, polynomial regression, and evaluation metrics such as R-squared and mean squared error.
Example use cases include price prediction and trend analysis.

## Classification
Contains supervised learning models used for categorical prediction.
Includes logistic regression, K-nearest neighbors, support vector machines, decision trees, and naive Bayes.
Example applications include spam detection, disease prediction, and customer churn analysis.

## Clustering
Focuses on unsupervised learning techniques used to group unlabeled data.
Includes K-means clustering and hierarchical clustering.
Common use cases include customer segmentation and pattern discovery.

## Reinforcement Learning
Introduces reinforcement learning fundamentals.

## Project – Titanic Survival Prediction
A complete end-to-end machine learning project.
Includes data loading, preprocessing, feature engineering, model training, evaluation, and prediction.
Uses the Titanic dataset to predict passenger survival.

## Hands on ML with Scikit-Learn (PDF)
Reference material covering machine learning concepts, scikit-learn workflows, and best practices.
Useful for theoretical understanding and revision.
